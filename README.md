# Real Estate Android Application

## 🏡 Overview

This project is an Android application developed for the **Advanced Computer Systems Engineering Laboratory (ENCS5150)** course.

The app simulates a real estate agency platform where users can **browse, favorite, and reserve properties**, while also providing an **admin panel** for managing users and system data.


## 🚀 Features

### 👤 User Features

* User Registration & Login (with validation & Remember Me)
* Browse properties by category (apartments, villas, lands)
* Search & filter properties (price, location, type)
* Add properties to favorites ❤️
* Reserve properties 📅
* View reservations and favorites
* Profile management (update info & profile picture)
* Contact agency (Call, Email, Map integration)

### 🛠️ Admin Features

* Delete users
* View all reservations
* Add new admin accounts
* Create featured properties ⭐
* Statistics dashboard:

  * Number of users
  * Reservations count
  * Gender distribution
  * Top countries

## 📱 App Structure

* Welcome Screen (API connection check)
* Authentication (Login / Register)
* Navigation Drawer-based UI
* Properties & Details (Fragments)
* Favorites & Reservations
* Admin Dashboard

## 🧰 Technologies Used

* Java (Android)
* SQLite Database
* REST API Integration
* SharedPreferences
* Fragments & Navigation Drawer
* Intents (Call, Email, Maps)
* Animations (UI interactions)
